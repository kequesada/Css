Position

La propiedad position controla cómo se posiciona un elemento en la página.

static: posición normal
relative: se mueve desde su posición original
absolute: se posiciona de forma absoluta
fixed: se queda fijo en la pantalla

Float y Clear

La propiedad float permite que los elementos se desplacen hacia la izquierda o la derecha dentro de su contenedor.

Flotando derecha

El texto se acomoda alrededor de los elementos flotantes.

clear: both: Elemento debajo de los elementos flotantes izquierdo y derecho, tambien se puede utilizar left o right por separado debajo de cada elemento flotante

Display

La propiedad display controla cómo se muestra un elemento en la página.

display: block = Elemento ocupa toda la línea
display: inline = Elemento se muestra en línea
display: inline-block = Elemento se muestra en línea pero con propiedades de bloque

Overflow

La propiedad overflow controla cómo se muestra el contenido que se desborda del contenedor.

overflow: visible
El texto largo se muestra completamente, incluso si se desborda del contenedor
overflow: hidden
El texto que se desborda del contenedor no es visible
overflow: scroll
Se muestra una barra de desplazamiento para acceder al contenido que se desborda del contenedor
overflow: auto
Se muestra una barra de desplazamiento solo si es necesario

Visibility

La propiedad visibility controla la visibilidad de un elemento sin afectar su espacio en el diseño.

visible: El elemento es visible
hidden: El elemento es oculto
collapse (simulado): El elemento es colapsado
